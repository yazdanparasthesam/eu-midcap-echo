Built an end-to-end EU mid-cap algo-trading system for [#smazoomcamp] capstone.

  Scraped BaFin/EQS-DGAP German ad-hoc disclosures as a novel alt-data source, scored with German financial-sentiment lexicon
  Trained DT / Random Forest / XGBoost / LogReg (Optuna-tuned) on ~260k rows × 250 features of prices + macro + disclosure events
  Ran four backtests (vectorized → exact reinvestment → risk-managed w/ stops, regime filter & Kelly sizing) vs DAX benchmark
  Automated daily runs via GitHub Actions cron, Streamlit dashboard + Telegram bot alerts, Docker container, tests & linting

Repo: https://github.com/yazdanparasthesam/eu-midcap-echo
